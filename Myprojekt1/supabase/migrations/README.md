# Будущие миграции

Здесь хранятся только новые последовательные изменения базы.

Правила:

- одна задача — один SQL-файл;
- файл должен быть безопасным и по возможности повторно запускаемым;
- никаких `drop table`, удаления колонок или массового удаления данных без
  отдельной резервной копии и проверки;
- после применения файл не переписывается;
- актуальное изменение также добавляется в `../current_schema.sql`.

Шаблон:

```sql
begin;

-- Изменение схемы или данных.

notify pgrst, 'reload schema';

commit;
```
