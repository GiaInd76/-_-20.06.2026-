# CSS Structure

Порядок файлов важен. Чем ниже файл подключен в HTML, тем выше его приоритет.

1. `base.css` - базовые переменные, общий каркас, типографика.
2. `components.css` - общие карточки, кнопки, модальные окна, товары.
3. `home.css`, `seller.css`, `admin.css`, `auth.css`, `seller-panel-workspace.css` - стили конкретных страниц.
4. `glass-theme.css`, `internal-pages.css` - стеклянная тема и внутренние страницы.
5. `overrides.css` - временный слой старых точечных правок. Новые крупные правки сюда не добавлять.
6. `theme-background.css` - единый фиксированный фон сайта. Фоновое изображение менять только здесь.
7. `responsive-mobile.css` - только телефонные правила.
8. `responsive-desktop.css` - только компьютерные правила.

Новая логика:

- если меняется общий вид компонента, править файл компонента или страницы;
- если меняется общий фон сайта, править только `theme-background.css`;
- если меняется только телефон, править `responsive-mobile.css`;
- если меняется только компьютер, править `responsive-desktop.css`;
- `overrides.css` постепенно чистить и переносить из него правила в нормальные файлы.
